🗣 Spoken commands

They work while an audio note is recording. Say the command on its own, with a short pause before and after. You can start with “writer”, for example “writer, pause”. Commands are not saved as notes.

  • pause or stop reading: pause the reading (the microphone stays on)
  • keep reading, continue or read: start or carry on reading
  • go back: the sentence before · repeat: this sentence again · next: the next sentence
  • next paragraph · previous paragraph
  • scratch that: delete the last thing you said (the recording is kept)
  • cut thirty seconds · cut last minute: cut words and recording, then keep recording
  • new note: finish this note and start the next one
  • send my notes: send to the Control Room
  • start over: back to the first sentence, this writing's notes go to Deleted notes (you can restore them), and a fresh note starts
  • faster · slower · normal speed: reading speed
  • bigger text · smaller text
  • flag this: mark this sentence to come back to
  • read that back: hear the last thing you said
  • undo that: undo the last scratch, cut or flag

A short beep means a command was heard. Two beeps mean a bigger change, such as start over.
